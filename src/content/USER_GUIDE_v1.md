# 快速开始
## 创建容器
点击边栏内的“创建容器”选项卡。

1. 选择希望使用的容器镜像。一般情况下，选择`Ubuntu 24.04`即可。

2. 选择容器要跑在哪个机器上。如果没有可使用的机器，可以联系管理员，申请获取机器使用权限。

3. 填写机器的基础信息。随后，根据你的算力需求，为你的容器配置好可调度资源。

点击`创建容器`按钮，则会自动跳转至“我的容器”页面。

4. 此时，会弹出弹窗，告知你ROOT的登录密码。请妥善保管它。

关闭弹窗，需在“我的容器”页面等待，当容器状态变为`运行中`，即代表创建成功。

>可以填入你的SSH公钥，方便日后用私钥持有者免密登录容器。

>如果容器状态变成了“异常”，可以自行删除异常容器并重新尝试。再次失败，可以联系管理员来协助解决问题。

## 使用容器
点击边栏内的“我的容器”选项卡。

1. 找到“我的容器”页面中，对应容器的卡片。记录下给定的`IP`、`端口号`。用鼠标单击对应内容，即可复制。

2. 建立连接。在你的设备上，打开命令行终端（Windows 可用 `PowerShell` 或 `CMD`；macOS/Linux 可用 `Terminal`）。输入如下命令：

```bash
ssh root@{第一步拿到的IP} -p {第一步拿到的端口号}
```

例如，我希望访问的容器的`IP`是 `192.0.2.0`，`端口号`是`24`，那么你应该用这个命令来访问：

```bash
ssh root@192.0.2.0 -p 24
```

3. 输入密码。

你的容器的ROOT访问密码，会在你创建容器的时候以弹窗的形式告知你。

如果你没有没能记下密码，可以前往容器详情页进行重置。

---

为了安全，在创建容器后，应当及时修改密码。

以 Ubuntu 为例，在与容器建立连接后，你可以用下面的命令修改你的容器登录密码：

```bash
passwd {你的新密码}
```

例如，我希望的新密码是`IlovePHP`，那我应该这样重置我的密码：
```bash
passwd IlovePHP
```

## 防止容器被删除

### 邮件通知非常重要
为保障使用者的权益，伏羲平台会通过邮箱向用户发送重要通知。包括`即将删除提醒`、维护通知等。

建议保持注册时提供的邮箱畅通，防止遗漏重要内容。

### 短期容器
 - `平台会清理低活跃度的短期容器`。平台会检查其上一次 SSH 登录的时间，并在 `7 天内未发生 SSH 登录时将容器删除`。
 - 容器创建时默认是短期容器。
 - 短期容器`无存储空间使用限制`。
 - 清理倒计时可以在容器卡片上查看。

### 长期容器
 - `平台会清理长期存储空间使用超限的长期容器`。存储空间使用`超限的7天后`，如果容器的存储空间依旧超限，系统会自动`将容器删除`。
 - 长期容器设置有`存储空间使用上限`。当达到给定的磁盘容量上限后，会被`冻结`。
 - 冻结后需联系管理员进行处置。解冻后仍不处理，容器会在3天后被再次冻结。
 - 长期容器`不会因活跃度被清理`。
 - 存储空间使用上限因机器而异。容器卡片会展示相关信息。

### 短期容器 与 长期容器 的转换
 - 如果需要将容器变为`长期容器`，勾选`长期`；
 - 如果需要将容器变为`短期容器`，取消勾选`长期`。

## 防止数据丢失

### 数据备份机制
伏羲平台采用`挂载`的模式保存用户数据。

数据的挂在范围是：`/root`、`/home/{由伏羲平台创建的容器合作用户}`。

为了避免备份机制失效：
- 你不应该：将重要数据放在没有被挂载的区域（E.g. `/data`）
- 你不应该：绕过伏羲平台创建容器内用户

### 容器恢复
如果你的容器在近期被删除，并希望恢复备份机制能保护的数据，你应该立刻联系系统管理员。

为了方便管理员操作，你应该提供你的`伏羲平台用户名`，并提供受影响容器的`容器名称`、`容器id`，以及相关`机器名称`。


# 多人共用容器

## 我是容器主人

1. 在“我的容器”中找到你希望共用的容器，点击进入对应容器的“详情页”。

2. 在容器“详情页”中，找到“用户管理”卡片，点击搜索框，找到你希望添加的用户，选中ta。

`合作者需要拥有自己的伏羲平台账号。`

3. 为ta选择权限身份。`管理员`会比`协作者`额外拥有的sudo的权力。（实际情况根据所选用的容器镜像为准。例如Alpine Linux 默认没有sudo）

添加合作者时，系统会以弹窗的形式告知你`合作者的密码`，确保你代为转告其容器访问密码。

## 我是合作者

1. 确保自己有容器所在机器的使用权。向容器主人询问容器所在机器的`机器名称`，然后，前往“创建容器”页面，查看“选择机器”一项中，有没有其描述的对应机器。

2. 向容器主人提供你的`伏羲平台用户名`、`注册邮箱`，方便对方为你添加权限。

提醒容器主人给予你最新的容器访问密码。

## 容器转让

你需要先邀请其它人与你共用容器。

1. 在“我的容器”中找到你希望共用的容器，点击进入对应容器的“详情页”。

2. 在容器“详情页”中，找到“用户管理”卡片，在容器内的用户里，找到你选定的容器新主人。将ta的权限设为`超级管理员`，即可完成转让。
---
转让后，你的权限会降级为`管理员`。对于被提拔的用户，ta的home目录会被归档。

例如，`demo_user`原来的目录放置在`/root/.collaborators/demo_user`，当ta在伏羲平台被提为`ROOT`，ta原来的目录会被放到`/root/.collaborators/.legacy_demo_user_时间戳`。

---
转让时，系统会以弹窗的形式告知原主人`新的ROOT密码`和`原主人的新密码`。
